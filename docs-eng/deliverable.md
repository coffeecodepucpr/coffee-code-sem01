# Deliverable | Week 01

[Português](../docs/entregavel.md) · English

Use this file as the final checklist before considering Week 01 done. It gathers what is **required** to submit: the extra challenges in `challenges.md` are optional.

## What needs to exist in the repository

### 1. `/docs` folder

- [ ] `docs/requisitos.md`: problem, target audience, functional and non-functional requirements
- [ ] `docs/historias-de-usuario.md`: at least 2-3 stories in the format `As a [user], I want [action], so that [benefit]`
- [ ] `docs/design-system.md`: colors, typography, spacing and main components
- [ ] `docs/arquitetura.md`: at least a first view of the parts of the system and their responsibilities (expected in more depth from experienced members, but everyone should have an initial version)

### 2. Figma prototype

- [ ] Frames created representing the project's main flow
- [ ] Screens connected and clickable in Prototype mode
- [ ] Shareable Figma link (view permission, at least) saved in the repository's `README.md`

### 3. Repository organization

- [ ] Main `README.md`, with at least: project name, short description, link to the Figma prototype, link or reference to the `/docs` folder
- [ ] Commit history with clear messages (it does not need to be perfect, but avoid generic messages like "changes" on everything)
- [ ] Experienced members: at least one Issue created and, ideally, a Pull Request practiced

## How to review before submitting

Before considering the week done, do this quick test: ask someone else (a Coffee & Code classmate, a friend, or even yourself reviewing after a while) to read only your `/docs` folder and navigate the Figma prototype, with no extra explanation. Can that person understand:

- [ ] What problem does the project solve?
- [ ] Who is the user?
- [ ] What does the system do, in practice?
- [ ] What would using the system be like, looking at the prototype?

If the answer is "yes" to all four questions, your submission is on the right track. If not, go back to the corresponding module and adjust.

## What is NOT expected this week

To make it clear and avoid unnecessary anxiety:

- No working code is expected yet.
- The Figma prototype is not expected to have perfect visual polish.
- `docs/arquitetura.md` is not expected to be complete and final, especially for people who are just starting.
- Not all requirements are expected to be 100% nailed down; it is normal for them to evolve in the coming weeks.

## Where to ask questions

Remember: Coffee & Code's weekly meetings exist exactly for this. If you get stuck at any point, bring a specific question to the meeting (or to Discord): "I got stuck on X, I already tried Y" usually gets solved much faster than "I didn't understand anything in module Z".

If you want to go beyond what was asked, see `challenges.md`.

Have a good week of work!
