# Design System

## Cores

### Cor principal

* Azul: #2563EB

### Cor secundária

* Azul claro: #DBEAFE

### Fundo

* Branco: #FFFFFF

### Fundo secundário

* Cinza claro: #F5F5F5

### Texto principal

* Preto: #1F2937

### Texto secundário

* Cinza: #6B7280

### Sucesso

* Verde: #22C55E

### Erro

* Vermelho: #EF4444

## Tipografia

Fonte principal:

* Inter

Títulos:

* Peso 700

Textos:

* Peso 400

Botões:

* Peso 600

## Espaçamento

* Pequeno: 8px
* Médio: 16px
* Grande: 24px
* Extra grande: 32px

## Componentes

### Botões

Botões com cantos arredondados e destaque na cor principal.

### Cards

Utilizados para apresentar profissionais e serviços.

### Inputs

Campos utilizados para pesquisa e cadastro.

### Avaliações

As avaliações serão representadas por estrelas e uma nota.

### Categorias

Cards utilizados para apresentar os diferentes tipos de serviços disponíveis.
