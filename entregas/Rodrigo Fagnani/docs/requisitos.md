# Requisitos - FixAqui

## 1. Problema

Encontrar profissionais confiáveis para realizar pequenos serviços pode ser difícil. Muitas pessoas dependem de indicações de amigos ou precisam procurar profissionais em diferentes lugares.

O FixAqui tem como objetivo reunir profissionais e clientes em uma única plataforma, facilitando a busca e solicitação de serviços.

## 2. Público-alvo

O sistema será destinado a:

* Pessoas que precisam contratar profissionais para pequenos serviços.
* Profissionais autônomos que desejam divulgar seus serviços e encontrar novos clientes.

## 3. Objetivo do sistema

Permitir que clientes encontrem profissionais de acordo com o tipo de serviço que precisam e possam solicitar um atendimento.

## 4. Requisitos Funcionais

### RF01 - Cadastro

O sistema deve permitir que usuários criem uma conta.

### RF02 - Login

O sistema deve permitir que usuários entrem em suas contas.

### RF03 - Busca de serviços

O sistema deve permitir que o cliente procure serviços por categoria.

### RF04 - Visualização de profissionais

O sistema deve permitir que o cliente visualize profissionais disponíveis.

### RF05 - Perfil do profissional

O sistema deve apresentar informações sobre o profissional, como nome, serviço oferecido e avaliações.

### RF06 - Solicitação de serviço

O sistema deve permitir que o cliente solicite um serviço.

### RF07 - Acompanhamento

O sistema deve permitir que o cliente acompanhe o status de uma solicitação.

### RF08 - Avaliação

O sistema deve permitir que o cliente avalie o profissional após a realização do serviço.

## 5. Requisitos Não Funcionais

### RNF01 - Usabilidade

O sistema deve possuir uma interface simples e fácil de utilizar.

### RNF02 - Responsividade

O sistema deve funcionar em computadores e dispositivos móveis.

### RNF03 - Segurança

Os dados dos usuários devem ser armazenados de maneira segura.

### RNF04 - Desempenho

As páginas devem apresentar carregamento rápido.

### RNF05 - Disponibilidade

O sistema deve estar disponível para utilização sempre que possível.
