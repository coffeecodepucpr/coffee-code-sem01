# Design System 

## 1. Objetivo

O Design System define os padrões visuais utilizados no sistema para manter as telas consistentes, simples e fáceis de utilizar.

## 2. Princípios

- **Simplicidade:** apresentar somente as informações necessárias.
- **Clareza:** utilizar textos e ações fáceis de compreender.
- **Organização:** separar informações por categorias.
- **Consistência:** manter os mesmos padrões de botões, campos e navegação.
- **Acessibilidade:** garantir contraste adequado e textos legíveis.

## 4. Tipografia

**Fonte:** Inter ou Arial.

- Título principal: 28 px, semibold.
- Título de seção: 20 px, semibold.
- Texto normal: 16 px.
- Texto secundário: 14 px.
- Botões: 14–16 px, semibold.

## 5. Componentes

### Botão primário
Utilizado para ações principais, como "Adicionar tarefa" e "Salvar".

### Botão secundário
Utilizado para ações alternativas ou menos importantes.

### Campo de formulário
Utilizado para entrada de nome da tarefa, login, senha e outras informações.

### Card
Utilizado para apresentar matérias, tarefas e indicadores de progresso.

### Barra de progresso
Utilizada para representar visualmente o percentual de tarefas concluídas.

### Badge de status
Utilizada para indicar estados como "Pendente" e "Concluída".

## 6. Layout

O sistema utilizará:
- Cabeçalho com identificação do sistema e usuário.
- Conteúdo principal organizado em cards.
- Espaçamento consistente entre elementos.
- Botões posicionados próximos às ações relacionadas.

## 7. Estados

Os componentes devem possuir estados de:
- Normal.
- Hover.
- Foco.
- Desabilitado.
- Erro.
- Sucesso.
