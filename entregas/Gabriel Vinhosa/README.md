# Biblioteca entre Colegas

Um app para estudantes emprestarem livros didáticos uns aos outros. A ideia veio de uma situação bem comum: você compra um livro caro que só vai usar durante um semestre, e quem já fez a matéria tem o mesmo livro parado em casa.

# O que o app vai fazer

cadastrar um livro para emprestar

buscar livros por matéria

pedir um livro emprestado

aceitar ou recusar pedidos

avisar o dono quando alguém pedir o livro dele

marcar o livro como devolvido

# Problema

Muitos estudantes compram livros caros para usar em uma única matéria, e colegas que já cursaram têm o mesmo livro sem uso.

# Necessidade e objetivo

Precisa existir um jeito fácil de descobrir quem tem o livro de uma matéria e pode emprestar. O objetivo é diminuir a quantidade de livros que o estudante precisa comprar.

# Quem vai usar

Os usuários principais são estudantes universitários, tanto quem procura um livro quanto quem tem um sobrando.
